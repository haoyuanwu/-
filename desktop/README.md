# Robot Eyes 桌面端

Flutter 桌面应用和 Dart HTTP 服务。macOS 与 Windows 使用同一套状态查询、手机连接和模型服务。

## 开发运行

在 Flutter Manager 导入本目录，选择 macOS 或 Windows 设备运行。终端也可以从本目录运行 `flutter pub get`，再使用 `flutter run -d macos` 或 `flutter run -d windows`。Windows 的原生构建需在 Windows 环境执行。

应用启动时会监听 `127.0.0.1:18792`。最小化或关闭主窗口时，服务继续在后台运行。点击 macOS 菜单栏或 Windows 通知区域的眼睛图标，可以查看服务状态、启动或停止服务、复制手机配对或 AI 配置，以及重新打开主窗口。「退出」会关闭应用和服务。

在 Windows 上，打开「电脑服务 → 开机自启」，下次登录后 Robot Eyes 会在托盘启动电脑服务。macOS 可通过系统登录项设置自动启动。

## 配对

1. 在 Windows 或 macOS 上连接 Tailscale。在桌面端「Tailscale 连接」点「重新检测」。若显示「已连接，待配置 Serve」，复制面板里的命令，在 Windows PowerShell 或 macOS 终端运行，然后重新检测。Windows 的命令可使用 Tailscale 安装路径，无需先把它加入 PATH。
2. 用 USB 连接安卓手机并授权调试。桌面端会检测已配置的 Serve 地址并自动更新手机上的远程配对。
3. 手机加入同一 tailnet。手动配对时，在桌面端点「重新检测」和「复制配对配置」，再粘贴到手机的「远程连接」。请把配对配置当作密码保管。
4. 如需关闭此转发，在电脑运行 `tailscale serve --https=8443 off`。

## USB 和局域网

- 安装 Android SDK Platform Tools 并授权 USB 调试后，桌面端自动检测连接并发送状态。多台手机同时连接时，可通过 `ANDROID_SERIAL` 指定设备。
- 安卓手机在同一可信局域网可以直接搜索桌面端。首次纯无线配对时，在桌面「手机连接 → 手机局域网 → 生成配对码」生成配对码，在手机上选择电脑并输入。已授权 USB 或已配对的 Tailscale 可以自动补齐局域网配置。手机保存多台电脑时，可从首页「电脑列表」切换当前电脑。桌面「手机连接」下的局域网和 Tailscale 列表分别显示已配对手机及在线状态，可同时显示多台在线手机。

## 桌面模型连接

添加模型时可选「本地模型文件」「本地模型服务」或「云端模型」。本地文件入口导入 GGUF 对话模型，由 Robot Eyes 通过 llamadart 运行。已运行 Ollama 或其他 OpenAI 兼容服务时，选择本地服务入口，填写服务地址并获取模型列表或手动填写模型 ID。Ollama 默认地址为 `http://127.0.0.1:11434/v1`。可保存多个连接，并选择手机通过电脑调用时的默认连接。本地文件和路径留在当前设备。

本地服务中的模型有变化时，在「电脑模型」点「同步本地模型」刷新模型列表，再从该连接的菜单切换模型 ID。支持 Ollama 模型信息接口的服务可在编辑页回显只读运行参数。

电脑服务运行时会定期检查已配置的模型服务。本地模型约每 5 秒检查一次，云端模型约每 30 秒检查一次。对于支持模型列表接口的服务，检查使用该接口。对话成功或失败也会立即更新连接状态。手机首页的「桌面模型连接」通过 USB、局域网或 Tailscale 同步名称、类型和连接状态。手机选择「电脑默认」时，电脑负责调用模型并保存密钥。

在「模型连接」添加 HTTPS 云端模型后，地址、模型 ID 和密钥会通过配对后的 Tailscale HTTPS 同步到手机的云端模型列表。可在桌面「手机模型」菜单点「同步云端列表到手机」，也可选「直连」指定当前模型。手机在「模型设置」修改已绑定的云端配置后，电脑也会更新该模型。手机离线时会保留已收到的配置，重新连接后补同步。

添加云端连接时，填好接口地址和密钥，点「获取模型列表」搜索并选择模型。保存连接后，其余模型 ID 随该连接保留，可从连接菜单的「切换模型 ID」选用。已绑定的手机会收到当前选中的云端模型。手机采用本机或局域网模式时，桌面只显示来源。

重连后如果两端的云端配置不同，先保留两边的配置。到「模型连接 → 手机模型」点「处理冲突」，可选择以电脑或手机为准，也可合并保留两套并选择当前使用的一套。合并后，两套配置都会在桌面连接列表和手机的云端模型列表里保留。

## 桌面 AI MCP

- 在「桌面 AI MCP」点「复制给 AI 配置」，或从 Windows 托盘、macOS 菜单栏的「复制配置」菜单复制。将整段内容粘贴到同一台电脑上的 AI 对话。AI 会按当前客户端格式配置本机 Streamable HTTP MCP，安装 [状态上报 Skill](skills/robot-eyes-reporting/SKILL.md)，并验证 `set_eye_state`。复制内容包含本机访问密钥，请粘贴到你信任的 AI 对话。
- 「查看配置详情」会显示通用 MCP 配置和上报 Skill，访问密钥以掩码显示。「AI 工具连接」按名称合并已初始化的本机 MCP 会话，显示工具名称和当前状态。配置面板会保留本次应用运行期间最近验证的客户端和时间。客户端关闭会话，或连续 2 小时没有请求时，会从连接列表移除。
- 手机主屏「AI 工具状态」按 MCP 客户端申报的名称显示已接入的工具。USB、局域网和 Tailscale 都会同步这个列表。

## Codex 用量和消息

- 两端均读取当前用户的 Codex 会话事件和有效用量窗口，默认目录为 `~/.codex/sessions`（Windows 为 `%USERPROFILE%\.codex\sessions`），支持 `CODEX_HOME`。用量随 Codex 写入会话日志更新。
- macOS 同时读取通过现有 `eyes agent` 注册的 Agent 状态。macOS 桌面包用于直接安装，以便访问同一用户的 Codex 会话目录。
- 配对密钥和手机消息保存在 macOS 的 `~/Library/Application Support/Robot Eyes` 或 Windows 的 `%LOCALAPPDATA%\Robot Eyes`。已有旧版数据目录时会继续使用原目录。桌面端收到消息后会提示，系统级通知取决于系统权限与免打扰设置。
